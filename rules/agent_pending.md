# 에이전트 판단 (보류)

사용자가 2026-11-24에 "보류, 일단 에이전트 판단 유지"로 정한 항목입니다.

- 회사규칙이 아닙니다. 규칙서(`prompts/system.md`)에 넣지 않고, 에이전트에게도 주지 않습니다.
- 에이전트는 이 부분을 매번 스스로 판단합니다.
- 채점기(정답모델기준)와 검사기(규칙직접비교)는 이 항목을 채점하지 않습니다.
- 사용자가 승인하면 규칙서로 옮기고 출처를 `[에이전트 제안·사용자 승인 <날짜>]`로 적습니다.

출처: 2026-11-18 제품군 실험에서 에이전트가 결과물 코드에 남긴 메모 (`generated_family/*_t2.py` PARAMS notes).

| # | 상품 | 에이전트가 정한 것 | 정할 것 |
|---|---|---|---|

| 4 | 상부장 | 다리 없음, 상판 아래 뒤쪽에 벽걸이 보강대(폭 100, 두께 18) | 거는 방식과 치수 |
| 5 | 키큰장 | 문 높이 1996을 위아래 나누지 않고 한 장 | 문을 위아래로 나누는 높이 |
